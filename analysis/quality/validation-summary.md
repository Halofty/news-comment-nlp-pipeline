## Reddit 판단

Reddit 표본은 공통 계약 변환의 정상 동작을 확인하기에는 충분하지만 데이터 분포 분석용 대표 표본은 아닙니다. `score`가 음수일 수 있다는 점, 작성자 없이 필요한 분석 필드를 구성할 수 있다는 점과 `language=unknown` 정책을 확인했습니다.

다음 품질 단계에서는 길이 상한, UTF-8 byte 수, 제어·zero-width 문자, 반복·도배와 개인정보성 문자열을 별도 quality flag로 정의해야 합니다. 이번 profile은 해당 규칙을 아직 적용하지 않습니다.

## GDELT 판단

Collector 변환은 단위 테스트로 검증했지만 실제 100건 계약 검증은 완료하지 못했습니다. 재검증할 때 다음 값을 profile에 추가합니다.

- 수집 성공·계약 통과·오류 건수
- 필수 필드 결측과 중복 `event_id`
- 언어와 도메인 분포
- 가장 이른·늦은 `event_time`
- 실제 query, 시작·종료 시각과 코드 revision

차단 상태를 이유로 빈 결과를 성공으로 처리하거나 예상 통계를 작성하지 않습니다.

## 공개 범위

profile에는 원문 텍스트, 사용자명, 원본 댓글 ID와 기사 URL 목록을 포함하지 않습니다. 집계 결과만 Git에 저장하고 재현에 필요한 원문·중간 데이터는 `data/`에 둡니다.
