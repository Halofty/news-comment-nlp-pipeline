# Historical 2012 기준선

이 디렉터리는 2012년 Google News 검색 결과와 Reddit archive로 검증한 v1 결과를
보존한다. 2026 current 전환 이후에도 당시 입력·처리 건수와 장애 복구 결과를 현재
운영 수치처럼 갱신하지 않는다.
