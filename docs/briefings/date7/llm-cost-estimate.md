# 2012년 1월 대주제별 LLM Batch 비용 예측

기준일은 2026-09-03이다. 실제 API는 호출하지 않았으며
`data/experiments/week5/january-recovery`의 전체 텍스트 길이를 스캔해 계산했다.
재현 가능한 상세 결과는
[`analysis/reports/llm-grouped-cost-estimate-2012-01.json`](../../../analysis/reports/llm-grouped-cost-estimate-2012-01.json)에
저장했다.

## 범위

- 기간: 2012-01-01~2012-01-31 및 1월 통합
- 대주제 4개: 각 5개 subreddit의 유효 댓글 전체
- 비교군: AskReddit에서 날짜별 네 대주제 평균 건수만큼 고정 표본 추출
- 뉴스: 대주제에는 같은 `google_news_topic_group`, AskReddit에는 4개 주제 전체
- 최종 결과: 일별 155개와 월별 5개, 총 160개
- 결과 저장 루트: `data/llm_response/`

## 가격 기준

GPT-5.6 Luna Batch의 short-context 가격인 입력 `$0.10/1M tokens`, 출력
`$0.60/1M tokens`를 적용했다. 모든 Map chunk를 원문 50,000토큰 이하로 제한하므로
272K 초과 long-context 가격은 적용하지 않는다는 가정이다. 캐시 할인은 계산하지
않았다.

공식 근거: [OpenAI 가격표](https://developers.openai.com/api/docs/pricing),
[Batch API](https://developers.openai.com/api/docs/guides/batch),
[GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna)

## 실제 입력 규모

| 그룹 | Reddit 처리 행 | 근사 원문 토큰 |
|---|---:|---:|
| 정치·국제 | 621,231 | 46,703,676 |
| 경제·사회 | 71,209 | 6,143,593 |
| 기술·디지털 | 121,079 | 8,787,410 |
| 환경·과학 | 207,981 | 11,103,496 |
| AskReddit 비교 표본 | 255,381 / 1,911,875 | 12,689,436 |
| 뉴스 4개 주제 | 2,456개 주제 할당 | 44,434 |

AskReddit 표본은 날짜별 반올림 때문에 월 전체 네 대주제 평균인 255,375건과
6건 차이가 난다. 입력 데이터는 이미 빈 값과 삭제 댓글이 제거된 상태이며,
16,000 bytes를 초과한 AskReddit 댓글 4건은 안전 상한까지만 계산했다.

## 요청 수

| 단계 | 예상 요청 | 보수적 최대 |
|---|---:|---:|
| Map 원문 chunk 요약 | 1,785 | 2,209 |
| 일별 Reduce | 155 | 155 |
| 월별 Reduce | 5 | 5 |
| 합계 | 1,945 | 2,369 |
| 최종 분석 결과 | 160 | 160 |

토크나이저를 직접 적용하지 않고 `ceil(UTF-8 bytes / 4)`로 추정했다. 보수적
최대치는 입력 토큰에 25% 안전 계수를 적용하고 모든 응답이 출력 상한을 사용한다고
가정했다.

## 비용

| 단계 | 예상 입력 토큰 | 예상 출력 토큰 | Batch 예상 비용 |
|---|---:|---:|---:|
| Map | 86,320,111 | 446,250 | $8.8997611 |
| 일별 Reduce | 612,618 | 38,750 | $0.0845118 |
| 월별 Reduce | 43,750 | 2,000 | $0.0055750 |
| 합계 | 86,976,479 | 487,000 | **$8.9898479** |

- Batch 예상 비용: 약 **$8.99**
- 동기 API 환산 비용: 약 **$17.98**
- 보수적 Batch 최대 비용: 약 **$11.64**
- 실제 비용은 API usage와 reasoning token 사용량으로 확정한다.

## 판단

전체 댓글을 LLM에 직접 입력한다는 조건을 유지하면 약 `$12`를 제출 예산 상한으로
두는 것이 적절하다. 비용 대부분은 Map 단계의 원문 입력이므로 chunk 크기를 키워도
큰 폭으로 감소하지 않는다. 비용을 수십 센트 이하로 낮추려면 Spark에서 전체 데이터의
빈도·통계·대표 표본을 먼저 만들고 LLM에는 압축 결과만 보내야 하며, 이는 “모든 원문을
LLM에 전달”하는 현재 조건과 다른 실험안이다.
